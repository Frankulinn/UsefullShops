# UsefullShops

Create shops opened by NPCs. UsefullShops uses [FancyNpcs](https://modrinth.com/plugin/fancynpcs) for the NPCs, [Vault](https://github.com/MilkBowl/Vault) for the economy, and works with **modded items** on hybrid servers such as **Youer 1.21.1** (Paper + NeoForge).

## Features

- Shops opened with a right click on a FancyNpcs NPC. A shop can have several NPCs; an NPC belongs to a single shop.
- **Modded items supported**: the whole item (data components, NBT, mod data) is saved, not just its type.
- Optional **access permission per shop**: only players who have it can open or buy from the shop.
- Decimal prices, lots of several items per purchase, purchase confirmation screen.
- Paginated menu, protected against click and drag duplication tricks.
- Purchase history (latest 100 transactions) and optional log file.
- Messages in French and English, fully editable.
- Public API and cancellable events for other plugins.

## Requirements

| Requirement | Version |
|---|---|
| Server | Paper or Youer **1.21.1** |
| Java | 21 |
| [FancyNpcs](https://modrinth.com/plugin/fancynpcs) | 2.9.2 |
| [Vault](https://github.com/MilkBowl/Vault) + an economy plugin providing Vault | any |

## Installation

1. Install FancyNpcs, Vault and an economy plugin.
2. Drop `UsefullShops-<version>.jar` into `plugins/`.
3. Restart the server. Edit `plugins/UsefullShops/config.yml` if needed and run `/us reload`.

## Quick start

```text
/us create bakery                      create a shop
/us rename bakery <gold>Bakery         set its title (MiniMessage)
/us additem bakery bread 12.50 4       sell the item in your hand: 4 for 12.50
/npc create baker                      create the NPC with FancyNpcs
/us npc add bakery                     then right click the NPC to bind it
```

Optionally restrict the shop to some players:

```text
/us restrict bakery                    requires usefullshops.shop.bakery
/us restrict bakery job.baker.shop     or any permission node of your choice
```

Give that permission to a group with your permission plugin. `/us unrestrict bakery` opens the shop to everyone again.

## Commands

The command is `/usefullshops`, with the aliases `/us`, `/ushop` and `/shops`.

| Command | Permission | Description |
|---|---|---|
| `/us create <shop>` | `usefullshops.admin.create` | Create a shop |
| `/us delete <shop> [confirm]` | `usefullshops.admin.delete` | Delete a shop |
| `/us list` | `usefullshops.admin.list` | List the shops |
| `/us rename <shop> <title>` | `usefullshops.admin.edit` | Change the menu title |
| `/us view <shop>` | `usefullshops.admin.view` | Open a shop, ignoring its restriction |
| `/us additem <shop> <key> <price> [amount]` | `usefullshops.admin.items` | Sell the item in your main hand |
| `/us removeitem <shop> <key>` | `usefullshops.admin.items` | Remove an item |
| `/us setprice <shop> <key> <price>` | `usefullshops.admin.items` | Change a price |
| `/us setamount <shop> <key> <amount>` | `usefullshops.admin.items` | Change the size of the lot |
| `/us items <shop>` | `usefullshops.admin.items` | List the items of a shop |
| `/us restrict <shop> [permission]` | `usefullshops.admin.permission` | Require a permission to use the shop |
| `/us unrestrict <shop>` | `usefullshops.admin.permission` | Make the shop public |
| `/us info <shop>` | `usefullshops.admin.permission` | Show the required permission |
| `/us npc add <shop> [npc]` | `usefullshops.admin.npc` | Bind a NPC (click it, or give its name) |
| `/us npc remove <shop> <npc>` | `usefullshops.admin.npc` | Unbind a NPC |
| `/us npc list <shop>` | `usefullshops.admin.npc` | List the NPCs of a shop |
| `/us history [count]` | `usefullshops.admin.history` | Show the latest purchases |
| `/us validate` | `usefullshops.admin.validate` | Check items and NPCs |
| `/us reload` | `usefullshops.admin.reload` | Reload configuration, messages and shops |

## Permissions

| Permission | Default | Description |
|---|---|---|
| `usefullshops.use` | everyone | Open a shop by clicking its NPC |
| `usefullshops.admin.*` | op | All the administration permissions above |
| `usefullshops.bypass.permission` | op | Ignore the access permission of shops |
| `usefullshops.shop.<shop>` | nobody | Generated by `/us restrict <shop>` |

## Configuration

`plugins/UsefullShops/config.yml`:

| Option | Default | Description |
|---|---|---|
| `prefix` | `[Shops]` | Chat prefix (MiniMessage) |
| `language` | `fr` | `fr` or `en` (`messages_<lang>.yml`) |
| `confirm-purchase` | `true` | Ask for confirmation before buying |
| `close-on-purchase` | `false` | Close the menu after a purchase |
| `permission-prefix` | `usefullshops.shop.` | Prefix of generated permissions |
| `npc-selection-timeout` | `30` | Seconds to click a NPC after `/us npc add` |
| `history.size` | `100` | Number of purchases kept |
| `history.log-to-file` | `false` | Also write every purchase to `logs/purchases.log` |

Shops are stored in `plugins/UsefullShops/shops/<shop>.yml`.

## Developer API

```java
UsefullShopsAPI api = Bukkit.getServicesManager().load(UsefullShopsAPI.class);
api.openShop(player, "bakery");
```

Events: `ShopOpenEvent` (cancellable), `ShopPurchaseEvent` (cancellable, before the money is taken) and `ShopPurchasedEvent` (after the purchase).

## Building

```bash
./gradlew build
```

The jar is produced in `build/libs/`. Java 21 is required.
